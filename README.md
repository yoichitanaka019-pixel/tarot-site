# Everyday Quick Tarot v27

GitHub Pages用の公開フォルダです。フォルダ内のファイルをリポジトリ直下へ配置してください。

## v27の主な変更
- 公開URLに合わせたcanonical、OGP、meta description、構造化データ
- sitemap.xml、robots.txt、favicon、OG画像
- 6カテゴリの視覚的な選択パネル
- GA4の主要行動イベント
- 結果画像の保存、Web Share、URLコピー
- カード画像のWebP化
- BGMの遅延読み込み
- Ko-fi外部ウィジェットを軽量なリンクへ変更
- 健康・ギャンブルを含む利用上の注意、プライバシー表示

公開URL: https://yo-create-wr.github.io/quick-tarot/

## BGMについて
元のv26配布ZIPにはMP3本体が含まれていなかったため、本ZIPにも音源は含めていません。公開中のリポジトリにある `music/top.mp3`、`music/shuffle.mp3`、`music/result.mp3` は残してください。
